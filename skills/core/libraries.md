## Page-weight budget

A typical report (React, one chart library, Mermaid) stays under 1.5 MB of decompressed JS. elkjs, p5, three and GSAP come on top only for pages that need them. Prefer Mermaid over React Flow + elkjs unless the diagram must be interactive.

## Library CSS

Artifact pages cannot fetch from a CDN, and a `<link>` may only load Google Fonts from outside the page. Library stylesheets ship in `vendor/`:

| File | For |
|---|---|
| `vendor/carbon-charts.css` | @carbon/charts-react 1.27.20 |
| `vendor/xyflow.css` | @xyflow/react 12.12.0 |

1. Copy the file into the working or scratchpad directory next to the page (the Artifact tool only publishes files from there).
2. Publish it with the page: `files: {"carbon-charts.css": "<path to the copy>"}`.
3. Link it: `<link rel="stylesheet" href="./carbon-charts.css">`.

For local HTML files, link the vendor file by relative path instead.

## Mermaid

Always style the block `pre.mermaid { margin: 0; overflow-x: auto; }`: where the diagram fails to render (a local file, a parse error), its source shows as text, and the long init line would otherwise widen the page.

**Artifacts** render `<pre class="mermaid">` natively; do not load the library. The renderer can't read CSS variables or re-render on a theme change, so write each diagram twice: one block with the look's light init values (class `mermaid mermaid-light`) and one with its dark values (class `mermaid mermaid-dark`), and show one per theme:

```css
.mermaid-dark { display: none; }
@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) .mermaid-light { display: none; } :root:not([data-theme="light"]) .mermaid-dark { display: block; } }
:root[data-theme="dark"] .mermaid-light { display: none; }
:root[data-theme="dark"] .mermaid-dark { display: block; }
```

The light block looks like this (the dark block repeats the diagram with the look's dark values):

```html
<figure>
<pre class="mermaid mermaid-light">
%%{init: {"theme": "base", "flowchart": {"nodeSpacing": 32, "rankSpacing": 48, "padding": 16}, "themeVariables": {"fontFamily": "IBM Plex Sans, system-ui, sans-serif", "fontSize": "16px", "primaryColor": "#f4f4f4", "primaryTextColor": "#161616", "primaryBorderColor": "#e0e0e0", "lineColor": "#525252"}}}%%
flowchart LR
  accTitle: Request path
  accDescr: A request goes from the browser to the API, which reads the database.
  Browser --> API --> DB[(Database)]
</pre>
<figcaption>Every request crosses one API hop.</figcaption>
</figure>
```

**Local HTML** loads Mermaid and re-renders on theme change:

```js
import mermaid from "https://cdn.jsdelivr.net/npm/mermaid@12.0.0/+esm";
const token = n => getComputedStyle(document.documentElement).getPropertyValue(n).trim();
async function drawDiagrams() {
  mermaid.initialize({
    startOnLoad: false, theme: "base",
    flowchart: { nodeSpacing: 32, rankSpacing: 48, padding: 16 },
    themeVariables: {
      fontFamily: token("--pa-font-sans"), fontSize: "16px",
      background: token("--pa-bg"), primaryColor: token("--pa-surface"),
      primaryTextColor: token("--pa-text"), primaryBorderColor: token("--pa-border"),
      lineColor: token("--pa-text-2"), secondaryColor: token("--pa-surface"), tertiaryColor: token("--pa-bg"),
    },
  });
  for (const el of document.querySelectorAll("pre.mermaid")) {
    el.dataset.src ??= el.textContent;
    const { svg } = await mermaid.render(`m${Math.random().toString(36).slice(2)}`, el.dataset.src);
    el.innerHTML = svg;
  }
}
await drawDiagrams();
new MutationObserver(drawDiagrams).observe(document.documentElement, { attributes: true, attributeFilter: ["data-theme"] });
matchMedia("(prefers-color-scheme: dark)").addEventListener("change", drawDiagrams);
```

`themeVariables` apply only with `theme: "base"` and need resolved colours, which is why they are read from computed style.

## Charts

- Carbon Charts: `import { SimpleBarChart } from "https://cdn.jsdelivr.net/npm/@carbon/charts-react@1.27.20/+esm"`, options `{ theme: dark ? "g100" : "white", legend: { alignment: "left" }, toolbar: { enabled: false } }`, plus `vendor/carbon-charts.css`. Re-render when `data-theme` or `prefers-color-scheme` changes, with the same observer as Mermaid.
- Recharts: colours from `--pa-cat-*`, axis and grid from `--pa-text-2` and `--pa-border`, `isAnimationActive={false}` under reduced motion, direct `<LabelList>` labels instead of `<Legend>`.
- Every chart's data is also written into the HTML as a `<table>` (see accessibility.md), so the page still reads if the CDN fails.

## Motion, explorables, 3D

- GSAP: `import { gsap } from "https://cdn.jsdelivr.net/npm/gsap@3.15.0/+esm"`. Guard every timeline with `if (!matchMedia("(prefers-reduced-motion: reduce)").matches)`.
- anime.js: `import { animate } from "https://cdn.jsdelivr.net/npm/animejs@4.5.0/+esm"`, same guard.
- p5.js: `import p5 from "https://cdn.jsdelivr.net/npm/p5@2.3.4/+esm"` in instance mode (`new p5(sketch, el)`), paused under reduced motion, with a range input for every parameter the text discusses.
- three.js: `import * as THREE from "https://cdn.jsdelivr.net/npm/three@0.186.1/+esm"`. Scene background from `--pa-bg`, never transparent over text. Provide a still image or a text description for print and reduced motion.
